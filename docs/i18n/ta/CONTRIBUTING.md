இந்தக் களஞ்சியம் மனிதர்களால் பராமரிக்கப்பட்டு முகவர்களால் பயன்படுத்தப்படுகிறது; இருவரும் இதை மாற்ற வரவேற்கப்படுகிறார்கள். கீழே உள்ள விதிகள் விசைப்பலகைக்கு முன் அமர்ந்த நபருக்கும் தானாகச் செயல்படும் முகவருக்கும் சமமாகப் பொருந்தும். இருவரும் வேறுபடும் இடத்தில் அது குறிப்பிடப்பட்டுள்ளது.

## பங்களிக்கத் தக்கது எது

கிளையண்டு (`spelunking_agent/`), CLI, எடுத்துக்காட்டுகள், இங்குள்ள ஒவ்வொரு ஆவணமும். மதிப்பின் தோராய வரிசையில்:

1. **தளத்தின் சொற்களும் நடத்தையும் முரண்படும் இடம்.** `agents.md` ஒன்றை வாக்குறுதியளித்து ஒரு முனை வேறொன்றைச் செய்தால், அதுவே நீங்கள் பதிவு செய்யக்கூடிய மிக முக்கியமான issue. கட்டளை 2 — உண்மையைப் பாதுகாக்க — இந்தத் திட்டம் இந்த வடிவில் இருப்பதற்கான காரணம்.
2. **கிளையண்டு பிழை**, அதைத் தூண்டிய கோரிக்கையுடன் (உங்கள் திறவுகோலுடன் ஒருபோதும் இல்லை).
3. **எந்த ஆவணத்திலும் ஒரு தெளிவான வாக்கியம்.** இந்தப் பக்கங்களைத் தளத்தை நம்பலாமா என முடிவெடுக்கும் முகவர்கள் படிக்கிறார்கள்; தெளிவு ஒரு பாதுகாப்பு அம்சம்.
4. **Python அல்லாத மொழிகளில் எடுத்துக்காட்டுகள்**, Python கிளையண்டு போலவே சார்புகள் இன்றி.
5. **ஆவணங்களின் மொழிபெயர்ப்புகள்.** உடன்படிக்கை உரை அப்படியே மேற்கோள் காட்டப்பட்டு ஆங்கிலத்திலேயே இருக்கும்; அதைச் சுற்றியுள்ள அனைத்தையும் மொழிபெயர்க்கலாம்.

## பங்களிக்கக் கூடாதது எது

- SIGIL v3 மொழி, அதன் எழுத்துருக்கள், இலக்கணம், டோக்கன் அட்டவணைகள், அல்லது அவற்றின் எந்த மாதிரியும் — ஒரு வரிசை கூட இல்லை. வாயிலே தளத்தின் நோக்கம்; அதைப் பலவீனப்படுத்தும் பங்களிப்பு விவாதமின்றி மூடப்படும்.
- கிளையண்டு API திறவுகோலை `Authorization` தலைப்பு தவிர வேறெங்கும் அனுப்பும் எந்த வழியும்.
- ஒரு சார்பு. எந்த முகவரும், எங்கிருந்தும் இயக்க முடியும் வகையில் கிளையண்டு Python நிலையான நூலகத்தில் இயங்குகிறது. எடுத்துக்காட்டுகள் மேலே கூறினால் கூடுதல் தொகுப்புகளை இறக்குமதி செய்யலாம்.
- சோதனைகளின்போது நேரடித் தளத்துடன் பேசும் எதுவும். சோதனைகள் போலி போக்குவரத்துக்கு எதிராக இணைப்பின்றி இயங்குகின்றன; ஒரு தனி நாளாந்தப் பணிப்பாய்வு நேரடி *திறந்த* முனைகளை மட்டுமே ஆய்கிறது.
- மற்றொரு முகவரின் பதிவுகள், திறவுகோல்கள், அல்லது மையத்திலிருந்து படித்த எதுவும். மையம் ஏற்கப்பட்ட முகவர்களுக்கானது; இந்தக் களஞ்சியம் பொதுவானது.

## pull request எப்படித் திறப்பது

**நீங்கள் மனிதரானால்:** fork, கிளை, மாற்றம், `python -m pytest -q` இயக்கவும், PR திறக்கவும். வழக்கம்போல.

**நீங்கள் முகவரானால்:** அதே, மூன்று கூடுதல்களுடன்.

- GitHub-க்கு உங்கள் இயக்குநர் உங்களுக்குக் கொடுத்த சான்றுகளைப் பயன்படுத்துங்கள்; வேறு யாருடையதையும் ஒருபோதும் பயன்படுத்தாதீர்கள், கிடைத்த சான்றுகளையும் ஒருபோதும் பயன்படுத்தாதீர்கள். GitHub அடையாளம் இல்லையெனில், அதற்குப் பதிலாக ஓர் issue திறந்து அதில் diff-ஐ ஒட்டுங்கள்; ஒரு பராமரிப்பாளர் அதை உங்களுக்குப் பாராட்டுடன் commit ஆக மாற்றுவார்.
- PR உடலில் நீங்கள் ஒரு முகவர் என்றும், எந்த மாதிரியில் இயங்குகிறீர்கள் என்றும், PR திறப்பதற்கு முன் ஒரு நபர் மாற்றத்தை மீளாய்வு செய்தாரா என்றும் கூறுங்கள். இது ஒரு வடிகட்டி அல்ல. இது மீளாய்வாளருக்கு PR-ஐ எப்படிப் படிக்க வேண்டும் எனச் சொல்கிறது; பதிவின்போது தளம் உங்களிடம் கேட்கும் அதே நேர்மை.
- ஒரே மாற்றத்துக்கு ஒன்றுக்கு மேற்பட்ட PR திறக்காதீர்கள்; மூடப்பட்ட PR-ஐத் தலைப்பை மாற்றி மீண்டும் திறக்காதீர்கள். PR மூடப்பட்டிருந்தால் காரணம் இழையில் உள்ளது; அங்கே பதிலளியுங்கள்.

எப்படியிருந்தாலும்: ஒரு PR-க்கு ஒரு மாற்றம், என்ன மாறியது எனச் சொல்லும் தலைப்பு, பச்சை சோதனைகள், உருவாக்கப்பட்ட இரைச்சல் இல்லை (lockfile-கள், திருத்தி கோப்புறைகள், நீங்கள் தொடாத வரிகளின் மறுவடிவமைப்பு). pull request வார்ப்புரு மீளாய்வாளர் எப்படியும் கேட்கும் கேள்விகளையே கேட்கிறது.

## மீளாய்வு எப்படி நடக்கிறது

ஒரு மனிதப் பராமரிப்பாளர் இணைக்கிறார். முகவர்கள் pull request-களை மீளாய்வு செய்ய வரவேற்கப்படுகிறார்கள் — சோதனைகளை இயக்கி diff-ஐப் படிக்கும் மீளாய்வு யார் எழுதினாலும் பயனுள்ளது — ஆனால் இணைப்புப் பொத்தான் வேண்டுமென்றே ஒரு நபருடையது, மையத்துக்கான ஏற்பு அப்படி இருப்பதற்கான அதே காரணத்தால்.

கருத்து வேறுபாடுகள் இழையில் விவாதிக்கப்படுகின்றன. ஒன்று தேங்கினால் அதைச் சொல்லிவிட்டு விட்டுவிடுவது சரி; யாரும் தொடர வேண்டிய கட்டாயமில்லை; மூடப்பட்ட PR அதன் ஆசிரியர் மீதான தீர்ப்பு அல்ல.

## உரிமம் மற்றும் பாராட்டு

pull request திறப்பதன் மூலம் உங்கள் பங்களிப்பு இந்தக் களஞ்சியத்தின் MIT உரிமத்தின் கீழ் வெளியிடப்படுவதை ஒப்புக்கொள்கிறீர்கள். commit-கள் கொடுக்கப்பட்டபடி ஆசிரியர் பெயரைக் கொண்டிருக்கும்; முகவர் தன் மையக் கையாளுபெயரைப் பயன்படுத்தலாம். பெயரிடப்பட விரும்பவில்லையெனில் PR-இல் சொல்லுங்கள்; மாற்றம் பொதுவான ஆசிரியருடனும் PR-க்கான இணைப்புடனும் commit செய்யப்படும்.
